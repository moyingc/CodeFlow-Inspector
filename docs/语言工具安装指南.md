# 语言工具安装指南

[English](Language-Tool-Installation.md) | [返回中文说明](../README.zh-CN.md)

## 是否必须安装

不是。CodeFlow Inspector 软件本体可以直接安装、启动和导入项目。

未安装下列语言服务器时，软件仍使用 Tree-sitter、Compiler 桥、本地规则和知识库完成基础解析；涉及跨文件类型、定义、引用、宏和编译诊断的结论会标记为缺少 LSP 证据，不会冒充完整语义分析。

这些工具只在分析对应语言时需要：

| 项目语言 | 可选工具 | 增强能力 |
| --- | --- | --- |
| Python | Pyright | 类型、定义、引用和诊断 |
| Java | Eclipse JDT LS | 类型图、注解、定义、引用和编译诊断 |
| C / C++ | clangd | 类型、宏、指针语义、引用和编译诊断 |
| Go | gopls | 包、类型、定义、引用和诊断 |
| Rust | rust-analyzer | crate、类型、所有权相关语义、定义和引用 |

## 安全说明

CodeFlow Inspector 不会静默联网或安装第三方软件。请只使用本页链接的官方来源，并在安装前查看相应项目的许可证。安装行为由操作系统、官方安装器或包管理器完成；CodeFlow Inspector 只检测和调用工具。

## 安装 Pyright

1. 从 [Node.js 官方网站](https://nodejs.org/en/download) 安装 Node.js。
2. 打开终端、PowerShell 或 Windows Terminal，运行：

```bash
npm install -g pyright
```

3. 验证：

```bash
pyright --version
pyright-langserver --version
```

官方说明：[Microsoft Pyright installation](https://github.com/microsoft/pyright/blob/main/docs/installation.md)。

## 安装 Eclipse JDT LS

JDT LS 当前至少需要 Java 21 才能启动。

1. 安装 Java 21 或更高版本，并确认：

```bash
java -version
```

2. 从 [Eclipse JDT LS 官方里程碑下载页](https://download.eclipse.org/jdtls/milestones/) 下载压缩包。
3. 解压后，将解压目录中的 `bin` 文件夹加入系统 `PATH`。
4. macOS 或 Linux 如遇执行权限错误，运行：

```bash
chmod +x /你的解压目录/bin/jdtls
```

5. 验证：

```bash
jdtls --help
```

官方说明：[Eclipse JDT LS repository](https://github.com/eclipse-jdtls/eclipse.jdt.ls#installation)。

## 安装 clangd

### macOS

安装 Apple Command Line Tools：

```bash
xcode-select --install
clangd --version
```

如果系统工具中没有 clangd，可按 [clangd 官方安装说明](https://clangd.llvm.org/installation) 安装 LLVM。

### Windows

从 [LLVM 官方发布页](https://github.com/llvm/llvm-project/releases) 下载 Windows 安装器。安装时启用将 LLVM 加入 `PATH` 的选项，然后打开新的 PowerShell 验证：

```powershell
clangd --version
```

### Debian / Ubuntu

```bash
sudo apt update
sudo apt install clangd
clangd --version
```

CMake 项目建议生成 `compile_commands.json`，否则 clangd 可能无法获得真实编译参数：

```bash
cmake -S . -B build -DCMAKE_EXPORT_COMPILE_COMMANDS=1
```

## 安装 gopls

1. 从 [Go 官方网站](https://go.dev/dl/) 安装受支持的 Go 工具链。
2. 运行：

```bash
go install golang.org/x/tools/gopls@latest
```

3. 验证：

```bash
gopls version
```

`gopls` 通常位于 `$HOME/go/bin`，CodeFlow Inspector 会检查该目录。官方说明：[gopls installation](https://go.dev/gopls/#installation)。

## 安装 rust-analyzer

1. 从 [Rust 官方工具链页面](https://www.rust-lang.org/tools/install) 安装 Rust。
2. 从 [rust-analyzer 官方发布页](https://github.com/rust-lang/rust-analyzer/releases/latest) 下载与操作系统和 CPU 架构匹配的二进制文件。
3. 按 [rust-analyzer 官方二进制安装说明](https://rust-analyzer.github.io/book/rust_analyzer_binary.html) 解压、重命名为 `rust-analyzer`，并放入系统 `PATH` 中的目录。
4. 补充 Rust 标准库源码并验证：

```bash
rustup component add rust-src
rust-analyzer --version
```

## 让软件重新检测

1. 完全退出 CodeFlow Inspector。
2. 安装并在新的终端窗口中完成上述版本验证。
3. 重新启动桌面程序。
4. 打开“硬实力”页面中的 **LSP Sidecar 管理**。
5. 工具状态应由 `missing` 变为 `system` 或 `managed`。

`system` 表示软件找到了用户安装的真实工具；它可以提供语义证据，但不会冒充由 CodeFlow Inspector 构建锁校验过的内置 sidecar。

## 仍然显示 missing

- 先完全退出并重新打开软件，安装后旧进程不会自动继承新的 `PATH`。
- 确认命令名称分别是 `pyright-langserver`、`jdtls`、`clangd`、`gopls` 和 `rust-analyzer`。
- macOS/Linux 可用 `command -v 工具名` 检查路径。
- Windows PowerShell 可用 `Get-Command 工具名` 检查路径。
- macOS 软件还会检查 `/opt/homebrew/bin`、`/usr/local/bin`、`/usr/bin`、`~/.cargo/bin`、`~/go/bin` 和 `~/.local/bin`。

如果命令在终端可用而软件仍显示 `missing`，请提交 GitHub Issue，并附上操作系统、CPU 架构、工具版本和 `command -v` 或 `Get-Command` 的脱敏输出。
