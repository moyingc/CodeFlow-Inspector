1. Tauri 本地桌面壳、多项目隔离、原生 SQLite、备份与恢复。
2. 15 种语言 Tree-sitter AST 主链，Compiler/LSP 语义增强和能力降级记录。
3. Node、Python、Java、Rust、C、C++ 受控运行、真实 DAP 断点、栈、作用域和变量回放。
4. 技术说明与功能解读，覆盖文件、函数、模块、主流程、算法和证据边界。
5. 本地知识包签名、隔离、回放、激活与回滚。
6. DeepWeb 可训练头、教师证据门禁、模型版本和训练历史。
7. FastAPI、Flask、Django、Express、Spring 进程内协议实验。
8. 上下文堆、字段/容器 points-to、动态派发候选、事件级并发与同步边。
9. Java、Rust、C/C++ 动态边界探针和运行轨迹补证。
10. Program Digital Twin、Z3 契约、反例调用链、候选 Diff、A/B 和写回回滚门禁。
11. 10,000 函数 points-to/污点基准；当前合成基准约 2.3 秒，固定点收敛。
12. 默认公网隔离；官方知识源公网许可与本机/私网许可分离，禁止权限继承和内外网桥接。

## 全语言口径

- “全语言 Core v1 成熟”表示当前声明支持的 15 种语言都有真实 AST 路径，不以启发式扫描冒充 AST。
- 有对应 Compiler/LSP 的语言继续获得类型、定义、引用和诊断增强。
- Swift 在 SourceKit 受公网隔离影响时使用受控 `swiftc -typecheck/-dump-ast`，仍属于真实编译器证据。
- SQL Language Server 不实现 CodeFlow 请求时标记为 `limited`；SQL 结构由 Tree-sitter 提供，不伪造 LSP 语义。
- 未经哈希认证的系统 PATH 工具只作为兼容性探测，不参与 portable sidecar 成熟认证。

## 网络边界

- 公网开关只控制公网知识更新，不控制本机 IPC。
- 回环和 RFC 私网地址必须通过 Tauri 私网端点校验；只接受字面 IP，拒绝域名以避免 DNS 重绑定。
- 项目运行器保持 OS 级断网隔离，不能继承知识更新许可。
- 软件不提供代理、端口转发、路由桥接或公网入站服务。
